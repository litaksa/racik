# TikTok Script (4 persona)

Gaya bahasa ikut `brand-voice` (santai, "kak/guys"), lalu cek hasil dengan `compliance-check`.
Satu brief -> 4 naskah (satu per akun). Jika produk tidak relevan untuk suatu persona, buat konten
nilai (edukasi/hiburan) tanpa produk dan tulis `PRODUK: tidak dipaksakan`.

## Persona
| Akun | Isi | Sudut produk yang wajar |
|---|---|---|
| EDU | tips Excel, skripsi (kuantitatif), IT dasar | alat kerja/belajar, template, gadget kerja |
| FOOD | review jajanan, resep anak kos, promo makanan | makanan/minuman, alat masak |
| TREN | tren luar negeri (Jepang, Korea, US) dijelaskan untuk orang Indonesia | produk viral, gaya hidup |
| GAME | klip gaming, tips, momen lucu | aksesoris gaming, voucher (dengan disclosure) |

## Format wajib per naskah
```
AKUN: EDU|FOOD|TREN|GAME
DURASI: 30-60 dtk
HOOK (0-2 dtk): <kalimat diucapkan>  | TEKS LAYAR: <maks 6 kata>
BAGIAN 2-10 dtk: masalah/konteks
BAGIAN 10-45 dtk: isi/demo (3 poin maks)
BAGIAN akhir: CTA ringan ("link di bio/keranjang kuning", "save buat nanti")
SHOT LIST: 4-7 shot bernomor (angle, apa yang direkam, durasi)
TEKS LAYAR: per bagian
CAPTION: <= 150 karakter, santai, ada disclosure jika ada link affiliate
HASHTAG: 3-5 (1 niche + 1 lokal + 1 luas), mis. #exceltips #skripsi #racuntiktok
DISCLOSURE: "#ad / link affiliate" atau label konten berbayar/affiliate TikTok jika ada produk
```

## Aturan hook (2 detik pertama)
- Mulai dengan hasil, pertanyaan, atau kesalahan umum: "Stop pake rumus ini buat skripsi", "Jajan 10rb tapi kenyang sampe malem?", "Di Jepang ini lagi viral banget", "Clutch 1v3 cuma modal ini".
- Visual bergerak di frame pertama (tangan, layar, makanan), bukan wajah diam.
- Teks layar hook <= 6 kata, besar, kontras.

## Aturan isi
- Satu pesan per video. Maks 3 poin.
- Klip gaming: hanya pakai rekaman milik user sendiri; jangan reupload klip orang lain.
- Tren luar: sebut sumber/negara, jangan klaim "viral" tanpa contoh link sumber di catatan.
- Makanan: tidak ada klaim kesehatan ("bikin kurus", "menyembuhkan").

## Contoh singkat (EDU)
AKUN: EDU | DURASI: 40 dtk
HOOK: "Rekap data kuesioner 100 responden cuma 1 menit?" | TEKS LAYAR: "100 responden = 1 menit"
2-10: "Masih ngitung manual satu satu? capek kak"
10-35: demo PivotTable: blok data -> Insert PivotTable -> drag variabel -> selesai
35-40: "save dulu biar gak lupa, template nya ada di bio"
SHOT LIST: 1) screen record Excel penuh 3 dtk 2) zoom ke menu Insert 2 dtk 3) drag field 5 dtk 4) hasil tabel 3 dtk 5) wajah/tangan + CTA 3 dtk
CAPTION: "skripsi kuanti wajib tau ini, save kak" | HASHTAG: #exceltips #skripsi #mahasiswaakhir #belajarexcel
